# ⚙️ Portfolio CMS / Admin Studio

One of the notable features of the portfolio is the built-in **Admin Studio**.

It allows portfolio content to be managed without directly editing the source code.

### Dashboard

```text
Admin Studio
│
├── Overview
│
├── Profile
│
├── Projects
│
├── Skills
│
├── Education
│
└── Messages
```

### Admin capabilities

* ✏️ Update profile information
* 🚀 Add projects
* 🗑️ Delete projects
* 🛠️ Update technologies
* ➕ Add skill groups
* 🗑️ Delete skill groups
* 🎓 Update education
* 📩 View stored contact messages
* 🔄 Reset portfolio data

### Data Storage

The current portfolio CMS uses **browser localStorage**.

```text
Portfolio UI
     ↓
Admin Studio
     ↓
localStorage
     ↓
Portfolio Data
     ↓
Live UI Update
```

> **Important:** This is currently a client-side portfolio CMS. It does not provide server-side authentication or database-backed content management.

# ⚡ Run Locally

## 1. Clone the repository

```bash
git clone https://github.com/kumarabhiraj05981-dot/abhiraj-portfolio.git
```

## 2. Enter the project

```bash
cd abhiraj-portfolio
```

## 3. Install dependencies

```bash
npm install
```

## 4. Start development server

```bash
npm run dev
```

## 5. Build for production

```bash
npm run build
```

## 6. Preview production build

```bash
npm run preview
```

# 🔐 Current Architecture Note

The portfolio is intentionally lightweight and currently operates without a dedicated backend.

### Current

```text
React
  ↓
Vite
  ↓
Browser
  ↓
localStorage
```

A future version could introduce:

